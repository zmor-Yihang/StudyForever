# Poll IO多路复用测试程序

本目录包含两个测试程序，用于演示poll IO多路复用的使用方法：

## 文件说明

- `poll_reader.c`: 使用poll进行非阻塞读取的程序
- `poll_writer.c`: 使用poll进行非阻塞写入的程序
- `Makefile`: 编译脚本

## 编译方法

```bash
make
```

## 使用方法

### 读程序

```bash
./poll_reader
```

该程序将：
1. 以非阻塞模式打开设备文件 `/dev/char_dev`
2. 使用poll等待设备可读
3. 当有数据可读时，读取并显示数据
4. 设置5秒超时，超时后显示提示信息

### 写程序

```bash
./poll_writer
```

该程序将：
1. 以非阻塞模式打开设备文件 `/dev/char_dev`
2. 等待用户输入命令
3. 使用poll等待设备可写
4. 当设备可写时，写入用户输入的命令
5. 输入"quit"退出程序

## 使用说明

1. **首先确保字符设备驱动已加载**：
   ```bash
   sudo insmod ../build_x86/LED.ko
   ```

2. **检查设备文件是否存在**：
   ```bash
   ls -l /dev/char_dev
   ```

3. **运行测试程序**：
   - 在一个终端中运行读程序：`sudo ./poll_reader`
   - 在另一个终端中运行写程序：`sudo ./poll_writer`

4. **测试步骤**：
   - 在写程序中输入命令：`on`、`off`或`toggle`
   - 观察读程序是否会接收到数据
   - 每次有效命令都会触发LED状态变化并唤醒读程序

## 注意事项

1. 这两个程序需要访问设备文件 `/dev/char_dev`，可能需要root权限
2. 程序使用非阻塞IO，不会无限期等待设备操作
3. 如果需要使用不同的设备文件，请修改源代码中的 `DEVICE_PATH` 宏定义
4. **重要**：只有输入"on"、"off"或"toggle"命令才会触发读程序，其他输入会被忽略
5. 这是由于字符设备驱动程序的实现方式决定的，只有这些特定命令才会设置flag并唤醒等待队列
