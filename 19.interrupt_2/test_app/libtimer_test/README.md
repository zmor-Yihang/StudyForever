# libtimer 库测试程序

本目录包含用于测试 libtimer 库的测试程序。

## 文件说明

- `test_libtimer.c`: 测试程序主文件，包含对 libtimer 库所有功能的测试
- `Makefile`: 编译配置文件
- `README.md`: 本说明文件

## 功能测试

测试程序包含以下测试项目：

1. **测试开启定时器** - 测试 `timer_open()` 函数
2. **测试设置定时器周期** - 测试 `timer_set_period()` 函数
3. **测试停止定时器** - 测试 `timer_close()` 函数
4. **测试定时器操作序列** - 测试完整的定时器操作流程
5. **测试错误处理** - 测试异常情况下的处理
6. **运行所有测试** - 执行上述所有测试

## 编译和运行

### 编译

```bash
make
```

### 运行

```bash
./test_libtimer
```

### 清理编译文件

```bash
make clean
```

## 前置条件

在运行测试程序之前，请确保：

1. 定时器驱动已加载
2. 设备节点 `/dev/timer_device` 存在
3. 有访问设备节点的权限

如果没有设备节点，可以尝试创建：

```bash
sudo mknod /dev/timer_device c <主设备号> <次设备号>
sudo chmod 666 /dev/timer_device
```

## 使用说明

运行测试程序后，会显示一个菜单，您可以选择：

- 输入 1-5 运行特定测试
- 输入 6 运行所有测试
- 输入 0 退出程序

## 测试内容

### 定时器开启测试

测试 `timer_open()` 函数是否能够成功开启定时器。

### 定时器周期设置测试

测试 `timer_set_period()` 函数，使用不同的周期值：
- 1000 毫秒（1秒）
- 500 毫秒（0.5秒）
- 2000 毫秒（2秒）

### 定时器停止测试

测试 `timer_close()` 函数是否能够成功停止定时器。

### 定时器操作序列测试

测试完整的定时器操作流程：
1. 开启定时器
2. 设置周期
3. 等待一段时间
4. 更改周期
5. 停止定时器

### 错误处理测试

测试异常情况下的处理：
- 无效的周期值（负数）
- 极大的周期值

## 注意事项

1. 本测试程序需要相应的定时器驱动支持
2. 测试过程中会有等待时间，用于观察定时器效果
3. 错误测试部分可能会产生错误信息，这是正常的
4. 如果设备打开失败，请检查驱动和设备节点
